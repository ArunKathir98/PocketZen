2 · Tech stack and packages

The dependency list is deliberately tiny: three runtime packages. Everything else is browser platform APIs.

2.1 Runtime dependencies (shipped to users)

PackageVersionRoleWhy this and not something else

lucide-react^1.61Icons as small SVG components (tree-shaken per import)Consistent outline style, no icon font download, only the icons used end up in the bundle.

2.3 Things we deliberately did not add

Not usedWhat we did instead
React RouterThe app has one URL. The active page is a tab state in App.jsx, remembered in localStorage. Fewer moving parts and no server rewrite rules.
Redux / ZustandOne Context (store.jsx) holding one JSON document, plus refs for the latest value. Easy to reason about and trivially serialisable to Drive.
Tailwind / a UI kitOne hand-written styles.css with CSS custom properties (design tokens), light/dark themes and a few reusable classes.
date-fns / moment~80 lines in util.js; dates are stored as 'YYYY-MM-DD' strings, which sort correctly and avoid time-zone bugs.
A crypto libraryThe Web Crypto API (PBKDF2, AES-GCM, SHA-256) built into every browser.
A PDF library (jsPDF…)Pages are drawn on a canvas and packed into a PDF by a 40-line writer, so any language and the ₹ symbol render correctly (standard PDF fonts can't).
The Google API client library (gapi)Plain fetch calls to the Drive REST API; only Google Identity Services is loaded as a script.
A backend framework or databaseNone. See chapter 1.
Small dependency surface = small bundle (about 440 KB of JavaScript, roughly 130 KB compressed, for the whole app), few security advisories to track, and nothing that can break on an upgrade except React and Vite.
