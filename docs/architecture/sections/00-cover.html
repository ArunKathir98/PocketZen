Conventions used in this document

Blue boxes add context you might otherwise miss.
Purple boxes explain why a design choice was made, including the alternatives that were rejected.
Green boxes call out the concrete advantage you get from a choice.
Amber boxes mark traps, limits and things that surprised us while building.

File paths are relative to the repository root. sub means a Google account's unique id (or the literal "local" for the no-account mode). Money amounts are plain numbers in the user's currency, except inside shared groups, where they are converted to whole minor units (cents) for exact arithmetic.

The five-minute summary

  1. PocketZen is a static single-page app. There is no PocketZen server. Cloudflare only serves the built files.
  2. All user data lives in one JSON document. It is kept in IndexedDB on the device and, for Google users, mirrored to a hidden file in the user's own Google Drive (drive.appdata).
  3. React state is a single Context (store.jsx). Every change goes through one function, commit(), which updates the UI, saves locally and schedules a Drive sync.
  4. Sign-in uses Google Identity Services (token model): the browser gets a one-hour access token and calls the Drive REST API directly.
  5. People without a Google account use a lite mode (Records, Categories, Accounts) that never leaves the device.
  6. Calculation-heavy features (loan interest, group settle-up, balances) are pure functions with no React inside, so they are easy to test.
  7. Shared groups are files in the admin's Drive that anyone with a link can view. Only the admin edits.
