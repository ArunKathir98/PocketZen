17.2 Conventions to keep

  • All writes go through commit() (via add/update/remove/setSettings). Never mutate data directly.
  • New collection checklist: emptyData() → normalize() → mergeData() → hasUserData() if relevant → page → tab.
  • Dates are 'YYYY-MM-DD' strings; times 'HH:mm'; timestamps are ms numbers (updatedAt, u).
  • Money is a plain number in personal data and integer minor units inside group maths.
  • Always await dialog helpers (confirm, alert, choose).
  • Effects that start something must clean up (StrictMode runs them twice in development).
  • Modals opened from inside a modal must be rendered after it (DOM order = stacking order).
  • Keep lib/* logic files free of React and DOM so they stay testable.
  • Background code must not open Google windows: check google.hasLiveToken() first.
  • Never add a secret to the project; only public identifiers belong in VITE_*.

17.3 Debug cheat-sheet

// DevTools console
Object.keys(localStorage).filter(k => k.startsWith('pz:'))      // every flag the app uses
JSON.parse(localStorage.getItem('pz:session'))                 // who is signed in, which mode
localStorage.removeItem('pz:tok')                              // pretend the Google token expired
localStorage.removeItem('pz:dirty:' + sub)                     // pretend nothing is waiting to upload
indexedDB.databases()                                           // is the 'pocketzen' database there?

17.4 Running a local copy end to end

  1. cp .env.example .env, fill the client id (and API key if you want group links).
  2. Add http://localhost:5173 to the OAuth client's origins (and the API key's referrers).
  3. npm install && npm run dev.
  4. Restart npm run dev after editing .env; Vite reads it only at start.
