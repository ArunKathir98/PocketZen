5 · Startup and routing flow

There is no router library. "Routing" is a chain of early returns in App.jsx. Read this chapter once and you know what the user sees in every situation.

5.1 What runs before React

1

index.html

An inline script reads localStorage['pz:theme'] and sets <html data-theme="light|dark"> before first paint, so there is no white flash in dark mode. Then it loads Google Identity Services (accounts.google.com/gsi/client, async defer) and the module /src/main.jsx.

2

main.jsx

In order: capturePendingJoin() (if the URL has ?view=<id> store the id in pz:pendingJoin and clean the address bar); import install.js (starts listening for beforeinstallprompt before React mounts, because the event can fire early); register one-time pointerdown/keydown listeners that unlock Web Audio (browsers only allow sound after a gesture); registerSW({ immediate: true }); finally render <StrictMode><AppProvider><DialogProvider><App /></DialogProvider></AppProvider></StrictMode>.

3

AppProvider (store.jsx)

Reads pz:session synchronously. If there is a session it loads that user's document from IndexedDB (asynchronously; one-time migration from the old localStorage copy), sets locked = !!data.pin and finally ready = true. Without a session ready is immediately true.

5.3 Which tabs exist

const TABS = [
  ['records',    'Records',    ListChecks,  Records],
  ['categories', 'Categories', LayoutGrid,  Categories],
  ['accounts',   'Accounts',   Landmark,    Accounts],
  ['budget',     'Budget',     PiggyBank,   Budget],
  ['emi',        'EMIs',       HandCoins,   Emi,       'showEmi'],
  ['groups',     'Groups',     Users,       Groups,    'showGroups'],
  ['loans',      'Loans',      Handshake,   Loans,     'showLoans'],
  ['reminders',  'Reminders',  BellRing,    Reminders, 'showReminders'],
  ['user',       'Profile',    CircleUserRound, User],
]
// lite (local) mode only gets these four:
const LITE_TABS = new Set(['records', 'categories', 'accounts', 'user'])
const tabs = TABS.filter(t => isLocal ? LITE_TABS.has(t[0]) : !t[4] || data.settings[t[4]])

The fifth array element is the settings flag that switches an optional page on. If the saved tab is no longer allowed (for example after disabling a page) the app falls back to Records.

5.4 Effects that live in App.jsx

  • Remember the tab in pz:tab.
  • Invite link while signed in with Google: enables the Groups page and jumps to it (the Join dialog then reads the pending id).
  • Reminder scheduler: checkDue(data) immediately, every 30 s, and whenever the tab becomes visible again; fired reminders become toasts. Skipped for locked sessions and local mode.
Why early returns instead of a router? The app is a single screen with tabs. A router would add a dependency and URL/rewrite concerns for no benefit, and every "state of the world" (loading, locked, public, logged out) is a different whole screen anyway, which early returns express most clearly.
StrictMode. In development React runs effects twice. Every effect that starts something (loading data, polling) cleans up after itself (an alive flag or clearInterval), so the double run is harmless. Keep that discipline when adding effects.
