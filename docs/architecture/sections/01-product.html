1.3 The constraints that shaped every decision

ConstraintConsequence in the design
"Your data stays yours" — no server holding financial dataData lives in the user's own Google Drive or on their device. The app is a static site. Even shared groups are files in the admin's Drive.
Free to runCloudflare Workers static assets (free), Google Drive (user's own quota), no database, no paid services.
Works like a phone appPWA: manifest, service worker, install prompt, offline cache, responsive layout from phone to monitor.
Some users won't use GoogleLocal-only lite mode with encrypted backups and a clean upgrade path to Drive.
No backend means no refresh tokens, no push server, no secretsShort-lived browser tokens cached carefully; reminders only fire while the app can run; only public identifiers (client id, API key) ship in the bundle.
Future maintainers are mostly front-end developersPlain React + Context, hand-written CSS, almost no dependencies, business logic isolated in pure functions.
The single most important decision is "no backend". It removes servers, accounts, databases, GDPR duties and running costs, and it makes the privacy promise literally true. The price is that everything a server normally does (sync, conflict handling, scheduling, sharing) has to be solved in the browser. Chapters 7, 8, 10 and 12 show how.
